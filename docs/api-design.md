# REST API проєкту Student Projects Hub

Базова адреса: `http://localhost:3000/api`

## 1. Таблиця ресурсів та ендпоінтів

| # | Ресурс | Метод | Призначення | Успіх | Помилки |
|---|--------|-------|-------------|-------|---------|
| 1 | `/teachers` | GET | Отримання переліку всіх викладачів | 200 | 500 |
| 2 | `/teachers/:id` | GET | Отримання картки конкретного викладача | 200 | 404 |
| 3 | `/teachers` | POST | Додавання нового викладача (адміністратор) | 201 | 401, 403, 422 |
| 4 | `/students` | GET | Отримання переліку всіх студентів | 200 | 500 |
| 5 | `/students/:id` | GET | Отримання картки конкретного студента | 200 | 404 |
| 6 | `/students` | POST | Реєстрація нового студента (адміністратор) | 201 | 401, 403, 422 |
| 7 | `/projects` | GET | Перелік студентських проєктів із фільтрацією та пошуком | 200 | 400 |
| 8 | `/projects/:id` | GET | Детальна інформація про конкретний проєкт | 200 | 404 |
| 9 | `/projects` | POST | Подання заявки на реєстрацію нового проєкту | 201 | 401, 422 |
| 10 | `/projects/:id` | PUT | Повне оновлення даних проєкту | 200 | 401, 403, 404, 422 |
| 11 | `/projects/:id` | PATCH | Часткове оновлення проєкту (наприклад, зміна статусу) | 200 | 401, 403, 404, 422 |
| 12 | `/projects/:id` | DELETE | Видалення проєкту з каталогу | 204 | 401, 403, 404 |
| 13 | `/projects/:id/reviews` | GET | Отримання списку всіх рецензій та оцінок до проєкту | 200 | 404 |
| 14 | `/projects/:id/reviews` | POST | Публікація нової рецензії та оцінки викладачем | 201 | 401, 403, 404, 422 |

---

## 2. Параметри рядка запиту (Query Parameters) для `GET /projects`

| Параметр | Тип | Приклад | Опис |
|----------|-----|---------|------|
| `teacherId` | int | `?teacherId=2` | Фільтрація проєктів за науковим керівником (`Teacher.id`) |
| `studentId` | int | `?studentId=5` | Фільтрація проєктів конкретного студента (`Student.id`) |
| `status` | enum | `?status=in_progress` | Фільтрація за статусом (`draft`, `in_progress`, `review`, `completed`) |
| `q` | string | `?q=portal` | Пошук проєктів за ключовим словом у назві або описі |
| `sort` | enum | `?sort=created_desc` | Сортування списку (`created_desc`, `created_asc`, `title_asc`) |
| `page` | int | `?page=1` | Номер сторінки для пагінації |
| `limit` | int | `?limit=10` | Кількість записів на одну сторінку |

---

## 3. Формат повідомлення про помилку

У разі помилок валідації (`422 Unprocessable Entity`), відсутності запису (`404 Not Found`), некоректних параметрів запиту (`400 Bad Request`) або проблем із правами доступу (`401` / `403`) сервер повертає стандартизований JSON-об’єкт:

```json
{
  "error": "VALIDATION_FAILED",
  "message": "Помилка валідації вхідних даних",
  "details": {
    "title": "Назва проєкту є обов'язковою та має містити щонайменше 5 символів",
    "repo_url": "Посилання має вести на репозиторій GitHub (https://github.com/...)"
  }
}
```
