## Про проєкт
**Student Projects Hub** — це сучасна інформаційна система для кафедри, призначена для централізованого обліку, моніторингу та рецензування студентських курсових, дипломних і науково-дослідних проєктів.

### Ключові можливості:
- Єдиний реєстр студентських проєктів з фільтрацією за статусом та науковим керівником;
- Закріплення проєктів за викладачами кафедри;
- Система рецензування та виставлення оцінок керівниками;
- Подання заявок на реєстрацію нових проєктів із клієнтською та серверною валідацією.
